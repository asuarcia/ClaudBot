# Claudbot

Turn Claude Code into a persistent, autonomous assistant that remembers your work, delegates to cheaper models, and keeps running when you're not at the keyboard.

Claude Code is already an excellent agent — it reads files, runs commands, browses the web, and edits code. What it doesn't do on its own is remember yesterday, keep working overnight, hand routine work to cheaper models, or travel with you between machines. Claudbot adds those.
